Aplikasi Pemantauan Kesehatan dan Pola Tidur Sederhana

Deskripsi:
Program berbasis konsol ini dirancang untuk melakukan manajemen data riwayat tidur pengguna, menghitung durasi tidur secara otomatis (termasuk penanganan pergantian hari), memberikan klasifikasi kualitas tidur, serta menyajikan laporan analisis statistik harian dan mingguan.

Spesifikasi:
a. Pengguna dapat menambahkan, mengubah, dan menghapus daftar riwayat tidur.
b. Sistem memberikan klasifikasi kualitas tidur ("Baik", "Cukup", "Kurang") dan catatan medis secara otomatis berdasarkan durasi riwayat.
c. Pengguna dapat mencari riwayat tidur berdasarkan kata kunci tanggal menggunakan sequentialSearchTanggal dan binarySearchTanggal.
d. Pengguna dapat mengurutkan daftar riwayat berdasarkan nilai durasi menggunakan selectionSortDurasi atau berdasarkan kronologi tanggal menggunakan insertionSortTanggal (Menaik/Menurun).
e. Sistem menyajikan laporan evaluasi mingguan berupa rata-rata durasi tidur harian dari maksimal 7 data terakhir beserta status kondisi kesehatannya.

Logic:
1. Daftar Riwayat Tidur
    Array dengan tipe data buatan polaTidur bernama tabTidur dengan kapasitas maksimum nMAX = 1000.
    Tipe data buatan polaTidur memiliki atribut Tanggal(string), WaktuTidur(tWaktu), WaktuBangun(tWaktu), Durasi(float64), Kualitas(string), dan Saran(string).
    Tipe data buatan tWaktu memiliki atribut Jam(int) dan Menit(int).
    Pencatatan total data yang tersimpan dikendalikan oleh variabel global nData.

2. Kalkulasi Otomatis & Klasifikasi Medis
    Fungsi hitungDurasi menghitung selisih waktu tidur dan bangun dalam satuan desimal jam. Jika total menit bangun kurang dari total menit tidur, logika if-else akan memproses penanganan lintas hari (pergantian malam).
    Fungsi kualitasDanSaran menentukan klasifikasi kualitas dan catatan medis menggunakan pointer (*kualitas dan *saran) berdasarkan nilai Durasi:
        - Durasi 7.0 s.d. 9.0 jam = Kualitas "Baik" (Pola tidur ideal).
        - Durasi > 9.0 jam = Kualitas "Cukup" (Durasi tidur berlebih).
        - Durasi < 7.0 jam = Kualitas "Kurang" (Durasi tidur kurang).

3. Sistem Validasi Binary Search (Flagging)
    Variabel kontrol boolean dataTerurut digunakan sebagai indikator urutan data.
    Nilai otomatis bernilai true hanya jika fungsi insertionSortTanggal dijalankan.
    Nilai akan di-reset menjadi false jika fungsi tambahRiwayat, ubahRiwayat, hapusRiwayat, atau selectionSortDurasi dijalankan untuk menjaga validitas algoritma binarySearchTanggal.

Func main (Menu Utama)
    Menampilkan fungsi sambutan Welcome satu kali di awal program.
    Melakukan perulangan menggunakan struktur for-loop dengan kondisi terminasi (pilihan != 7) tanpa keyword break/continue.
    Menampilkan menu melalui fungsi CetakMenu dan menerima masukan angka switch-case:
        case 1: Input Riwayat Tidur baru
        case 2: Cetak dan Urutkan Riwayat Tidur
        case 3: Cari Riwayat Tidur Berdasarkan Tanggal
        case 4: Edit Riwayat Tidur
        case 5: Hapus Riwayat Tidur
        case 6: Cetak Laporan Evaluasi Mingguan
        case 7: Selesai

Func tambahRiwayat
    Memasukkan data riwayat tidur baru pada array tabTidur di indeks nData jika kapasitas belum penuh, memanggil hitungDurasi dan kualitasDanSaran, lalu menaikkan nilai nData++.

Func ubahRiwayat
    Mencari indeks tanggal lama menggunakan fungsi pembantu cariIdxTanggal. Jika ditemukan (idx != -1), memperbarui parameter Tanggal, WaktuTidur, WaktuBangun, Durasi, Kualitas, dan Saran dengan data yang baru.

Func hapusRiwayat
    Mencari indeks tanggal target menggunakan fungsi cariIdxTanggal. Jika ditemukan, melakukan perulangan for-loop untuk menggeser elemen array ke kiri (tabTidur[i] = tabTidur[i+1]) guna menghapus data secara fisik, lalu menurunkan nilai nData--.

Func cetakSemuaData
    Menampilkan semua data riwayat tidur yang tersimpan menggunakan perulangan for-loop dari indeks i = 0 sampai i < nData ke layar konsol.

Func selectionSortDurasi
    Mengurutkan data di dalam array tabTidur berdasarkan nilai atribut Durasi secara naik (ascending) atau turun (descending) menggunakan algoritma Selection Sort.

Func insertionSortTanggal
    Mengurutkan data di dalam array tabTidur berdasarkan nilai atribut Tanggal secara naik (ascending) atau turun (descending) menggunakan algoritma Insertion Sort.

Func sequentialSearchTanggal
    Melakukan pencarian linier dari indeks awal hingga data ditemukan atau batas nData tercapai untuk mencari kecocokan targetTanggal pada array.

Func binarySearchTanggal
    Melakukan pencarian bagi-dua pada array tabTidur yang sudah terurut berdasarkan targetTanggal menggunakan variabel batas kiri, kanan, dan tengah.

Func tampilkanHasilCari
    Menerima parameter indeks hasil pencarian. Jika indeks valid (idx != -1), mencetak detail data riwayat tidur lengkap ke layar. Jika tidak, menampilkan pesan bahwa data tidak ditemukan.

Func tampilkanLaporanMingguan
    Memeriksa kondisi data, mengambil maksimal 7 data terakhir dari array tabTidur (menggunakan startIdx = nData - 7), menghitung total durasi, rata-rata harian, serta memberikan analisis kesimpulan kondisi kesehatan mingguan pengguna.
