### Deskripsi Program
Program ini merupakan aplikasi berbasis konsol yang dirancang untuk mengelola data riwayat tidur pengguna secara digital. Sistem mampu melakukan perhitungan durasi tidur secara otomatis, memberikan klasifikasi kualitas tidur, melakukan pengurutan dan pencarian data, serta menyajikan analisis rekapitulasi data mingguan.
